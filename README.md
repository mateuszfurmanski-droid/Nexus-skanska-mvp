# NOSMO Nexus x SKANSKA MVP

Editable source project containing two independent demonstrators:

- `/spark-skanska-demo` (also `/residential`) — Spark 4.0 residential circular construction;
- `/skanska-property-demo` (also `/property`) — commercial property operations and Building Graph.

Run `npm install` and `npm run dev` for local development. Run `npm run build` to produce the static site in `dist/`.

All project and operational records shown in the demonstrators are synthetic demo data.
